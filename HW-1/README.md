# 📄 HW1 - Document question answering

A Streamlit app that answers questions about an uploaded `.txt` or `.pdf` document using
OpenAI's GPT models. Built on top of the Lab 01 Document QA template.

### How to run it on your own machine

1. Install the requirements

   ```
   pip install -r requirements.txt
   ```

2. Run the app

   ```
   streamlit run HW1.py
   ```

3. Enter your OpenAI API key, upload a `.txt` or `.pdf` file, pick a model, and ask a question.

### Model comparison

See [MODEL_COMPARISON.md](MODEL_COMPARISON.md) for the write-up comparing
gpt-3.5-turbo, gpt-4.1, gpt-5-chat-latest, and gpt-5-nano on the same document/question.
